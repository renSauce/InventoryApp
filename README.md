I have made a tracking system in C# with the GUI kit Avaloniaui. 
The customer can request an order. The order is routed in the orderbook, and checks wether the prerequested item is in stock in the inventory, 
if true, the order is moved from queued to processed.
The Robot arm then moves to the predetermined coordinate and picks the item in order with the new gripper, 
after being gripped the item is moved to the shipping box.
Furthermore the user can change the IP adresses trough inputs in the GUI.
